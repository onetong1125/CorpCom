# 开发路线

| 进度 | 工作 | 验证方式 |
| --- | --- | --- |
| 已验收 | 提示词与上下文预算 | 同一会话追问时载入最新档案，超出预算时缩减模型输入，刷新仍可回看完整的已记录过程。2026-11-19 已完成手动页面验收。[预算规则](backend-api.md#服务配置) |
| 已实现 | 跨会话研究记忆 | 工作笔记供同一工作区接手任务，项目判断与全局偏好按作用域保存。回归测试覆盖新会话读取、跨工作区复用用户偏好、修订和忘记。[使用说明](workspace-local.md#跨会话记忆) · [Agent 测试](../tests/test_workspace_agent.py) |
| 待验收 | 单 Agent 完整研究流程 | 从页面发起真实研究，逐项核对来源、工具结果和落盘文件，重新打开工作区后引用已有证据继续追问。[研究案例](research-workspace.md) |
| 计划中 | 多 Agent 协作 | 在同一案例中验证任务委派、证据汇总及部分失败处理，与单 Agent 比较研究质量、耗时和调用开销。 |

新闻采集、假设版本管理和定时执行尚未排期。
