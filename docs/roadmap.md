# 开发路线

单 Agent 工作台已支持多会话研究、共享工作区文件、工具执行、逐轮流式输出和历史恢复。已结束的研究可以从 checkpoint 和归档事件还原工具过程，旧会话也可以按用户消息读取历史。相关回归见 [历史合并测试](../tests/test_run_history.py) 和 [HTTP 接口测试](../tests/test_api.py)。

## 开发顺序与进度

| 顺序 | 工作 | 验收目标 |
| --- | --- | --- |
| 1 | [提示词与上下文管理](prompt-and-context-plan.md)（已验收） | 每轮提示词反映当前研究档案。长对话和大工具结果经压缩后仍能继续研究，刷新可回看完整的已记录过程。 |
| 2 | [跨会话研究记忆](cross-thread-memory-plan.md)（设计已确认，待实现） | 通过工作笔记跨会话接续任务，通过用户级和工作区级长期记忆复用偏好、判断和证据；页面可分别查看两类记忆。 |
| 3 | 单 Agent 全流程验收 | 从页面发起真实研究，核对来源、工具结果与落盘文件，重新打开工作区后继续追问。 |
| 4 | 多 Agent 协作 | 选定一个研究案例，验证任务委派、证据汇总及部分失败处理，并与单 Agent 比较研究质量、耗时和调用开销。 |

研究案例还描述了新闻更新、假设版本和定时执行。这些属于长期产品设想，尚未排期。[研究案例与报告约定](research-workspace.md)
