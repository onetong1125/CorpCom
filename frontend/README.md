# CorpCom 前端

Vue 3 与 Vite 构建的本地研究工作台。完整环境配置见[项目快速开始](../README.md#快速开始)。

## 本地开发

后端启动后，在 `frontend/` 下运行：

```bash
npm ci
npm run dev
```

开发服务监听 [127.0.0.1:5174](http://127.0.0.1:5174)，将 `/api` 代理到 `http://127.0.0.1:8001`。若后端端口不同，可以用 `CORPCOM_API_URL=http://127.0.0.1:8000 npm run dev` 启动，也可在 `frontend/.env.local` 中设置该变量。模型密钥在后端配置。

## 会话、记忆与文件

- 研究空间保存研究档案和文件，每个会话独立保留问答。按 Cmd/Ctrl + Enter 发送，Enter 换行。切换会话时，当前页面会保留各会话的草稿。
- 点击「记忆」查看当前工作区的工作笔记，或在长期记忆中切换项目主题和全局偏好。[记忆范围与文件位置](../docs/workspace-local.md#跨会话记忆)
- 展开某轮的研究过程可查看工具参数、结果或错误。运行期间可以切换会话、发起另一个研究或上传资料。已登记的报告和数据可在产物区预览或下载。
- 刷新或重新打开会话后，运行中的研究从 Redis 回放并继续接收事件，已结束的研究从历史接口加载。连接中断后，页面使用已收到的 Run ID 和游标重连。手动再次发送会创建新一轮研究。[流式执行、重连与历史](../docs/backend-api.md#流式执行重连与历史)

## 测试与构建

```bash
npm test
npm run build
npm run preview
```

构建输出位于 `dist/`。本地预览使用 [127.0.0.1:4174](http://127.0.0.1:4174)，沿用开发代理。单独托管静态文件时，需要由托管服务将 `/api` 转发给后端。
